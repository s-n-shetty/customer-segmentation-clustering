# Customer Segmentation using Clustering

## Overview
This project explores customer segmentation using unsupervised learning techniques. The goal was to identify meaningful groups within the dataset to better understand customer behavior patterns.

## What I Did
- Cleaned and standardized the data
- Applied K-Means clustering
- Used the Elbow method to determine optimal clusters
- Interpreted and compared segment characteristics

## Why It Matters
Customer segmentation helps businesses tailor marketing strategies, improve targeting, and make more informed decisions.

## Tech Used
Python, Pandas, Scikit-learn, Matplotlib
